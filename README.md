# Tra cứu phi tròng tối đa (ODS Lens Lookup)

Ứng dụng web tra cứu đường kính khả dụng tối đa (phi tròng tối đa) cho các dòng tròng kính:
- **SV VIP 1.67** (Aspherique Mr7 SF)
- **SV VIP 1.60** (Aspherique MR8 SF Extended)
- **RX PAL 1.60 sht/reg** (FBS Mr8 SF)
- **RX PAL 1.67 sht/reg** (FBS Mr7 SF)
